# Oracle

A versatile blockchain project featuring an Oracle interaction interface and a Monad NFT card demonstration system.

## Project Structure

The project consists of two main modules:

1. **Oracle Interaction Interface** - Located in the root directory
   - Interactive Star Divination Interface
   - Voice Input Functionality
   - Dynamic Starry Sky Animation Effects
   - Energy Release Interaction System

2. **Monad NFT Card Demo** - Located in `mingrate/monad-nft-card-demo`
   - Hardhat-based Smart Contract Development
   - React Frontend Interface
   - NFT Minting and Display Functionality

## Quick Start

### Environment Requirements

- Node.js 16+
- pnpm or npm
- MetaMask Wallet

### Install Dependencies

```bash
# Root Project
npm install

# NFT Demo Project
cd mingrate/monad-nft-card-demo
npm install
```

### Configuration and Running

#### Oracle Interface

```bash
npm run dev
```

#### Monad NFT Demo

1. Configure environment variables (refer to `.env.example`)
2. Configure MetaMask to connect to Monad Testnet
3. Deploy contracts and launch frontend
